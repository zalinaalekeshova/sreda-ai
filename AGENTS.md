# Работа над sreda.ai

Пользователь просит после каждой завершённой правки проверять изменения,
создавать коммит и отправлять его в настроенный GitHub origin. Не запрашивать
повторное согласие на обычный push согласованных правок. Перед push проверять
diff, не включать посторонние изменения, секреты или временные файлы. Не делать
force push. Если авторизация или push недоступны, явно сообщить, что не отправлено.

GitHub Pages публикуется автоматически workflow после push в main.
Перед коммитом выполнить проверку синтаксиса и сборку; UI-изменения проверить
в браузере. Исходники находятся в этой папке, dist генерируется и не коммитится.
Токен Telegram хранится только в Google Apps Script, никогда не добавлять его
в репозиторий. Публичный URL formEndpoint секретом не является.
